# DecodeLabs Task 2: Sensor Data Simulation 📟

## Project Overview

This project demonstrates sensor data collection using software simulation. 
The system generates simulated temperature and humidity sensor readings, displays the values, and stores the generated data for future analysis.

## Objective

- Understand sensor data collection
- Simulate IoT sensor readings
- Display sensor values
- Store generated sensor data

## Features

- Temperature sensor simulation
- Humidity sensor simulation
- Real-time data generation
- Sensor data logging
- Simple IoT data handling

## Technologies Used

- Python
- Random Module
- Time Module
- CSV Module

## Project Structure

DecodeLabs_Task2/

│── sensor_simulation.py  
│── sensor_data.csv  
│── README.md  

## Working Principle

1. The program generates random temperature and humidity values.
2. Sensor readings are displayed on the screen.
3. Generated data is stored in a CSV file.
4. The stored data can be used for monitoring and analysis.

## How to Run
python sensor_simulation.py
